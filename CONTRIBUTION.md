# Contribution Guidelines

All changes to this repository, whether proposed by external contributors or core maintainers,
must be submitted via pull requests. Direct commits to the main branches are prohibited. 

Each pull request requires at least one approving review and successful completion of all
automated checks before it can be merged. No exception is made based on project role or
permissions. Maintainers are expected to follow the same review workflow to ensure code
quality and shared accountability.
